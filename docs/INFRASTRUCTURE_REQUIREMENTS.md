# Attendance Management System — Server Requirements (Small / ~300–400 users)

For **100–400 employees** (web + mobile API, PostgreSQL, selfies on Cloudinary): **1 small API server — 2 CPU cores, 4 GB RAM, 40 GB SSD**; **1 PostgreSQL — 2 CPU cores, 4–8 GB RAM, 50 GB SSD**; **HTTPS + domain**. No separate web server (static site on CDN). Budget: **~$50–$120/month** (Cloudinary separate).
